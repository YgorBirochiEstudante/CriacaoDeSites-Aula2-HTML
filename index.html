1. Listas Não Ordenadas

Utilizam a tag <ul>. Os itens aparecem com marcadores (bullets). O atributo type define o estilo: disc, circle ou square.

2. Listas Ordenadas

Utilizam a tag <ol>. Os itens são numerados automaticamente. O atributo type define o tipo: 1, a, A, i ou I. O atributo start define o início da numeração.
